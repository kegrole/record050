# shellscan

纯 Python 标准库实现的 shell 注入**静态**分析器：把待检值代入命令模板，
按引号层级判定该值是否仍能影响命令结构。**只分析，不执行任何命令**——
包内没有任何进程创建 / 命令执行调用，测试会扫描源码保证这一点。

## 支持的 Shell 语法范围

词法切分（shellscan/lexer.py）支持：

- 单引号：内部完全字面量，反斜杠也不特殊
- 双引号：内部仍识别 $VAR、${VAR}、$(...) 与反引号；反斜杠仅在 $、反引号、
  "、\\、换行之前起转义作用
- 反斜杠转义与反斜杠续行（裸词位置反斜杠转义任意下一个字符）
- 注释：# 出现在词首时，到行尾为止
- 分隔符：; | & < > 及 && || ;; >> << >& <& 等组合，换行作为命令终结
- 命令替换：$(...) 与反引号，可互相嵌套（$(...) 内部是全新的命令上下文）
- 变量展开：$VAR 与 ${VAR}（${...} 支持嵌套花括号配对）

已知简化：反引号内部不再递归识别 $(...) 与变量展开（POSIX 允许实现
按字面预处理）；不做通配符 / 花括号展开的语义求值。

## 引号层级判定规则

把模板中的 %s 占位符替换为待检值后，用词法状态机确定值首字符的落点，
layer 取值恰好为以下四种之一：

| layer | 含义 | 判定 |
| --- | --- | --- |
| 单引号 | 值落在单引号内 | 安全：单引号内不发生任何展开 |
| 双引号 | 值落在双引号内 | 含 $、反引号、反斜杠或换行则危险（变量展开 / 命令替换在双引号内依然生效）；值中的未转义 " 会先闭合模板引号，其后出现分号等分隔符即判危险；普通文本安全 |
| 裸词 | 值落在无引号位置 | 危险：分号、换行、管道等会终结 / 拼接命令，且分词、通配、展开都会生效 |
| 命令替换内 | 值落在 $(...) 或反引号内 | 危险：命令替换会执行命令，值成为被执行命令的一部分 |

层级优先级：单引号 > 命令替换内 > 双引号 > 裸词（按最内层上下文判定）。
另外还会检查值是否落在命令位置（分隔符 / 行首之后的第一个词），若是，
危险结论的 reason 中会额外注明。

## 使用

```bash
python -m shellscan.cli --sinks demo/sinks.json --out out/report.json
```

运行结束后在 stdout 打印一行摘要（检查条数、危险数、安全数），并把逐条
结论写入报告。报告每条包含 sink_id、template、value、verdict（危险 / 安全）、
layer、reason 六个字段，只含静态分析结论，不含任何命令执行结果。

sink 定义格式（demo/sinks.json）：

```json
{"sinks": [{"sink_id": "example", "template": "echo '%s'", "value": "hello"}]}
```

模板中必须恰好包含一个 %s 占位符。

## 测试

```bash
cd tests && python -m unittest test_shellscan -v
```

或在仓库根目录运行 python -m unittest tests.test_shellscan -v。
测试覆盖 10 条判定夹具（恰好 6 危险 4 安全）、词法切分、命令替换与变量
展开识别，以及"实现不执行任何命令"的源码扫描。
